# 名字大乱斗：丝瓜uli攻击动画与特效方案

## 1. 角色结构

丝瓜uli不是普通的单线阶段升级，而是在半血转职时根据队伍条件进入两条不同路线：

```text
虚拟歌姬
├── 没有同队克蕾儿：瓦学妹
└── 存在同队克蕾儿：专属辅助
```

三种身份使用同一个视觉母题连接：蓝色蝴蝶。

- 虚拟歌姬：蝴蝶化作音符、声波和舞台灯光。
- 瓦学妹：蝴蝶碎片重组为准星、弹道和战术界面。
- 专属辅助：蝴蝶双翼化作护盾、治疗无人机和支援网络。

主色采用丝瓜现有立绘的黑、深蓝、青蓝和珍珠白，不采用常见的粉色偶像风。

## 2. 动画等级

- 普通攻击：短促枪击、声波或支援动作，约 0.35-0.6 秒。
- 一般技能：舞台内完整动作，约 0.7-1.3 秒。
- 特殊技能：燃曲压轴、残局处决、摸鱼伙伴羁绊，约 1.2-1.8 秒。
- 转职：独立显示前后职业的阶段切换动画。
- 瓦学妹终极技能：先播放约 0.45 秒战术切入，再进入对应舞台效果；不统一播放长时间全屏必杀。

## 3. 虚拟歌姬视觉语言

一阶段重点不是个人伤害，而是让整个队伍进入丝瓜的演唱会。

- 舞台核心绑定丝瓜角色节点，不能默认出现在战场中心。
- 团队效果使用声波、光轨或蝴蝶实际传播到每一名受影响队友。
- 攻击、治疗、防御、控制和净化必须拥有不同的命中语言。
- 同一次演唱只播放一次主动作，后续队友获得效果的日志不能重复演唱动画。

## 4. 歌姬演唱效果分类

| 效果类别 | 对应结果 | 动画方案 |
| --- | --- | --- |
| 团队治疗 | 甩葱歌、治愈之音、粉丝回馈、润喉糖 | 声波从丝瓜向队友扩散，蓝色蝴蝶落到每名队友身上并转为恢复粒子。 |
| 攻击强化 | 演唱会模式、大声应援 | 节拍器加速，队友脚下亮起同步节奏环，攻击图标随重拍点亮。 |
| 防御强化 | 摇滚反击、耳机隔音、星光护幕、粉丝护卫队 | 分别使用音箱反震、耳机隔音罩、聚光灯幕和人群剪影，不能共用同一个通用护盾。 |
| 速度与闪避 | 节奏加速、舞台烟雾 | 音轨向前流动；烟雾中出现多只蝴蝶残影。 |
| 控制敌人 | 高音爆发、绝美舞姿 | 高音形成压缩声波撞击目标；舞姿使用蓝色光带缠绕魅惑目标。 |
| 燃曲压轴 | 全属性强化 | 舞台灯光依次点亮，声浪扩散至全队，背景短暂出现大型蝶翼均衡器。属于特殊演出，但不是全屏必杀。 |

## 5. 摸鱼伙伴羁绊

1. 丝瓜与兔卷卷角色卡之间闪过一条“确认摸鱼”的细线。
2. 两张角色卡靠近并牵手向舞台侧面滑出。
3. 身后留下青蓝与粉色两条轨迹，并短暂出现奶茶杯剪影。
4. 场外期间彻底隐藏角色卡，只保留场外OB状态标识。
5. 正常回归时，两人从同一侧拿着奶茶走回战场。
6. 紧急回归时，奶茶被丢开，两张角色卡快速冲回自己的位置。

回归不能使用复活、传送或重新召唤动画。

## 6. 转职为瓦学妹

1. 演唱会灯光突然熄灭。
2. 音频波形压平为水平枪线，舞台网格重组为战术地图。
3. 蓝色蝴蝶碎裂为准星四角。
4. 麦克风轮廓折叠成枪械轮廓。
5. 显示「虚拟歌姬 -> 瓦学妹」。
6. 经济、终极点数和准星专注HUD依次上线。

瓦学妹的设计与《VALORANT》强相关，不只是借用颜色或枪械：枪支购买、经济、架枪、转点、准星专注、残局决策和特工终极技能都必须进入动画语言。

## 7. 瓦学妹枪械动作

| 技能 | 动画方案 |
| --- | --- |
| 标配(Classic) | 单手点射，短促枪口火焰和弹壳；稀有爆头出现红白击杀标记。 |
| 狂徒(Vandal) | 三发受控扫射，枪口逐步上扬，三处命中火花依次出现。 |
| 冥驹(Operator) | 目标周围出现圆形镜片暗角，准星收缩后重枪声命中，丝瓜角色卡产生明显后坐力。 |
| 架枪预瞄 | 丝瓜固定在掩体边缘，视线锥和准星持续锁住枪线。 |
| 提前枪 | 目标尚未完成行动，丝瓜先横向peek并开枪，截停标记在命中帧出现。 |
| 残局爆头线 | 横向急停、单发爆头、击杀标记，整个过程干净利落。 |
| 残局处决 | 短暂进入子弹时间，准星精确锁住弱点，再以单发重击结束；不播放全屏大招。 |

枪械弹道可以是直线，但必须同时拥有枪口火焰、武器后坐力、弹壳、准星和命中反馈，不能表现为普通角色共用的发光直线。

## 8. 瓦学妹战术状态

| 状态或资源 | 表现方式 |
| --- | --- |
| 准星专注 | 准星围绕角色卡逐层闭合，获得层数时增加刻度，消耗时对应刻度熄灭。 |
| 经济 | 使用购买阶段HUD和武器价格信息，不在战场中央掉落金币。 |
| 终极点数 | 角色卡边缘的终极槽逐格充能，满点时显示短促战术提示。 |
| 冥驹惩罚 | 角色卡进入架枪姿态，移动轨迹暂时锁定。 |
| 身位重置 | 战术地图路径快速重绘，角色卡横移到新的架枪点。 |
| 残局模式 | 其他区域轻微降暗，丝瓜角色卡出现CLUTCH边框和呼吸式准星。 |

这些资源变化必须绑定丝瓜角色卡，不允许像早期欧气效果一样错误出现在战场中心。

## 9. 瓦学妹终极技能统一规则

每次终极技能先播放约 0.45 秒的统一战术切入：

```text
TACTICAL ULT
特工剪影 / 技能名称 / 目标信息
```

随后进入对应的独特舞台动画。

- 同一次连续技能只播放一次战术切入。
- 《飓刃》击杀刷新时只补充飞刀，不重复播放开场。
- 范围技能必须根据实际受影响目标逐个结算命中反馈。
- 被法术抵挡、伤害转移或目标提前死亡时，动画必须遵循真实结算结果。
- 终极技能虽然醒目，但触发频率高于一次性必杀，不统一占用两三秒全屏动画。

## 11. 转职为专属辅助

1. 同队克蕾儿出现危险警报。
2. 聚光灯从丝瓜转向克蕾儿。
3. 蓝色蝴蝶分裂成两半，一半留在丝瓜，一半飞向克蕾儿。
4. 演唱会界面重组为支援指挥界面。
5. 显示「虚拟歌姬 -> 专属辅助」。
6. 两张角色卡之间短暂建立蓝色支援链。

这个分支不能表现为粉色婴儿风，也不能和玄凝的「水人的好大儿」混淆。其核心是丝瓜为了保护克蕾儿转为高科技专属辅助。

| 协助射击 | 丝瓜从克蕾儿侧后方探出，以蓝色光线枪补射目标。 |
| 卫星打击 | 扫描框锁定目标，细小定位束先落下，随后轨道炮命中。 |
| 爱的鼓励 | 蝴蝶应援牌在克蕾儿身后展开，攻击和魔力图标依次点亮。 |
| 弱点扫描 | 扫描线由头到脚掠过敌人，防御弱点被方框标出。 |
| 纳米护盾 | 两片蝶翼合拢包住克蕾儿，转化为透明六边形护盾。 |

## 13. 实现约束

- 建立独立的丝瓜特效主题，并拆分为diva、valorant、baby三组视觉提示。
- 蓝色蝴蝶是跨职业统一母题，但三组技能拥有不同粒子、动作和HUD语言。
- 歌姬随机池的每个结果保存结构化视觉类型，界面不得通过文本正则猜测效果。
- 团队技能事件必须带上全部实际受益者ID，声波依次传播到真实目标。
- 枪械攻击的命中时刻与伤害数字、受击动画和日志严格同步。
- 范围终极技能按实际结算顺序逐个播放目标反馈。
- 《飓刃》连续击杀、《再火一回》回归和《复活》重新入场需要专用动画队列。
- 场外OB期间不保留角色节点供任何攻击动画定位。
- 同一次行动只有第一条权威技能事件启动主动画，解释伤害、状态和范围余波的后续日志不能重播角色动作。
- 所有光效绑定施法者或目标节点，不允许默认落在战场中心。
- 为歌姬十五种结果、七种枪械动作、十二种终极技能和九种辅助技能建立独立预览入口。
- 提供低动态版本，关闭大幅位移、长时间闪光和全屏震动，同时保留枪械、歌姬和支援技能的辨识度。

## 14. 图片资源清单

项目现有 `public/Model.webp` 足以用于虚拟歌姬和第一轮特效原型。完整上线建议补充：

1. 瓦学妹持枪透明底全身立绘。
2. 专属辅助透明底全身立绘。
3. 虚拟歌姬、瓦学妹、专属辅助三种职业的方形头像。
4. 标配、狂徒、冥驹的透明武器素材。
5. 晚安火炮使用的火箭筒透明素材。
6. 五把飓刃的透明素材。
7. 单独的蓝色蝴蝶标志。

资源建议：

- 原图使用透明PNG，接入项目时统一转换为WebP。
- 全身立绘高度至少1600px，完整保留头、脚、武器和蝶翼。
- 不携带背景、文字、预制光效和边缘裁切。
- 武器保持侧视或稳定三分之四视角，便于翻转和旋转。
- 不需要准备十二套VALORANT特工立绘；特工能力使用抽象剪影、技能符号、战术HUD和Canvas特效表现。

现有 `public/Model2.webp` 的表情和动作更适合残局处决、摸鱼回归或嘲讽类短切入，不适合作为专属辅助的常驻立绘。
