# 名字大乱斗：刺猬人攻击动画与特效方案

## 1. 设计目标

刺猬人的动画不能只是统一的绿色攻击特效，而应表现三种力量逐层叠加：

- 一阶段「特摄粉」：尚未真正变身的模仿、憧憬与青涩感。
- 二阶段「奇迹武刃」：黑绿武刃、悲愿、居合与瞬间缩短间合。
- 三阶段「奇迹怪兽武刃」：保留武刃剑术，叠加怪兽拳套的星形力量与彩虹炼金。

武刃形态的官方设定强调剑术、瞬间踏入间合、重装甲和披风干扰，适合作为二阶段冷峻、克制的动作基础：

- [假面骑士太狸 武刃形态官方设定](https://www.tv-asahi.co.jp/geats/rider/tycoon/bujin_sword/stand.html)

彩虹歌查德的官方设定强调持续再炼成、装甲重构、治愈、解毒与《Rainbow Fever》，适合作为三阶段炼金、防御和终结技的表现基础：

- [假面骑士彩虹歌查德官方设定](https://www.tv-asahi.co.jp/gotchard/rider/gotchard/rainbow/stand.html)

## 2. 三阶段视觉语言

### 一阶段：特摄粉

- 主色：白、荧光绿。
- 动作直接但不华丽，保留模仿英雄的青涩感。
- 腰带投影允许轻微不稳定，真正变身前不应拥有成熟的武刃装甲表现。

### 二阶段：奇迹武刃

- 主色：黑、墨绿、冷银。
- 关键词：寂静、悲愿、居合、瞬间贴近、黑色剑气。
- 斩击强调短暂蓄势和延迟爆发，不使用普通直线光束代替刀术。

### 三阶段：奇迹怪兽武刃

- 基底仍是黑绿武刃。
- 怪兽力量使用金黄、深蓝和星形拳套语言。
- 彩虹只在炼金、防御、重构和《彩虹狂热》中完全释放，避免所有技能都变成无差别彩色特效。

## 3. 动画等级

- 普攻：短动作与命中特效，约 0.35-0.55 秒。
- 一般技能：舞台内完整动作，约 0.7-1.3 秒。
- 特殊演出：武神王座、悲愿不倒，约 1.2-1.8 秒，不占用全屏必杀。
- 变身：独立的阶段切换动画，明确显示前后职业。
- 必杀：只有《GREAT MONSTER VICTORY》和《彩虹狂热》使用全屏演出。

一阶段技能名虽然是《特摄必杀》，动画分类仍属于一般技能，不能因为文本含有“必杀”就播放全屏动画。

## 4. 一阶段技能分镜

| 技能 | 动画方案 |
| --- | --- |
| 普通攻击 | 角色卡小幅冲刺，以不稳定的绿色拳风命中，表现尚未真正变身。 |
| 骑士踢 | 角色卡后撤蓄力，沿弧线跃起，绿色足部光环锁定后斜向踢落。 |
| 特摄必杀 | 根据实际随机结果分为骑士踢、十字光线、战队火箭炮、英雄冲拳四种小型演出；由技能事件明确提供类型，不由界面猜测文本。 |
| 变身预演 | 腰带扫描线经过身体，短暂浮现奇迹武刃轮廓，随后装甲散去；锁头状态以绿色准星收束。 |
| 特摄魂 | 背后亮起模糊骑士剪影，绿色火焰从脚底升起，异常状态以碎片形式剥离。 |

## 5. 一阶段转二阶段

1. 战场短暂降暗，腰带扫描线锁定刺猬人。
2. 显示「特摄粉 -> 奇迹武刃」。
3. 黑绿装甲从四周闭合，披风和武神之刃最后出现。
4. 武神之刃出鞘，绿色交叉斩切开旧职业卡面。
5. 新职业卡面与立绘完成显现。

变身演出必须使用专用的刺猬人主题，不与必杀全屏动画混用。

## 6. 奇迹武刃技能分镜

| 技能 | 动画方案 |
| --- | --- |
| 武神之刃 | 刺猬人瞬间贴近目标，拔刀时只出现一条细绿线；穿过目标后延迟爆出黑绿交叉斩痕，再返回原位。 |
| 黑气斩波 | 原地横挥，巨大黑色弧形剑气冲向主目标，命中后分裂为两道较小余波追击其他目标。 |
| 悲愿居合 | 画面短暂降噪变暗并闪过一次心跳红光；刺猬人消失后出现在目标身后，收刀时才结算伤害，随后悲愿能量回流治疗。血量越低，刀光越粗、黑雾越浓。 |
| 奇迹魔法 | 五层炼金圆环锁住目标，彩色几何线条收束成结晶冲击，命中后形成短暂眩晕符文。 |
| 奇迹炼金 | 环形炼金阵围绕角色旋转，破损装甲碎片倒放重组，异常状态被抽离，最后形成薄型法术护层。 |
| 炼成护甲 | 银黑装甲板逐块扣合到角色卡边缘，外层亮起绿色六边形护罩；重点表现加厚装甲，不与治疗动画混用。 |
| 武神王座 | 黑绿王座从角色身后升起，角色卡后移入座，周围粒子突然安静；等待期间保留低亮王座虚影。受到攻击时冻结来袭动作，再由王座屏障压碎攻击。 |

王座共鸣必须绑定刺猬人的角色节点，以王座纹章逐格点亮，不允许默认出现在战场中心。

## 7. 二阶段转三阶段

1. 攻击触及武神王座，画面定格。
2. 黑绿屏障挡住来袭，王座出现裂纹。
3. 显示「奇迹武刃 -> 奇迹怪兽武刃」，不得出现同阶段转同阶段。
4. 怪兽星形拳套从两侧撞入，武刃装甲被彩虹炼金线重新缝合。
5. 播放文字「DUAL ON！GREAT！MONSTER！Ready Fight.」。
6. 变身完成后再播放《GREAT MONSTER VICTORY》，两段动画必须排队，不能重叠。

## 8. 奇迹怪兽武刃技能分镜

| 技能 | 动画方案 |
| --- | --- |
| 怪兽重拳 | 刺猬人贴近目标后挥拳，巨型星形拳套投影延伸，将目标卡向上轰飞；击飞状态下次行动时再播放坠落震动。 |
| 能量粉碎 | 两只怪兽巨臂从左右夹住目标，护盾和增益以环形符号显现，随后被炼金压力压碎成碎片。 |
| 奇迹炼成装甲 | 五元素炼金环依次点亮，黑绿怪兽装甲被彩虹材质重新覆盖，最终形成厚重虹色外壳。 |
| 武神怪兽连斩 | 刺猬人依次冲到最多三个目标附近，怪兽拳套握住武神之刃连续重斩；每个目标拥有独立命中时刻。 |
| 怪兽咆哮 | 胸前星形能量核膨胀，释放金蓝色同心冲击波；所有受害者卡片依距离依次震动，被击飞者额外上抬。 |
| 二阶段旧技能 | 保留原有黑绿动作并增加少量怪兽拳套残影；只有炼金技能增加彩虹表现。 |

## 9. 必杀技

### GREAT MONSTER VICTORY

1. 全屏切入奇迹怪兽武刃立绘。
2. 星形拳套逐级充能。
3. 刺猬人冲向目标，巨大星形拳印压下。
4. 中央爆出黑绿、金黄双层冲击。
5. 命中后星光回流治疗，再返回正常舞台。

演出顺序固定为「全屏蓄力切入 -> 返回舞台 -> 角色卡冲向目标 -> 怪兽拳套命中 -> 星形冲击与恢复结算」。若必杀由三阶段变身立即触发，则先完整播放「奇迹武刃 -> 奇迹怪兽武刃」，再按上述顺序播放必杀；舞台攻击不得在全屏动画背后被跳过。

该技能在三阶段变身后立即反击时，必须等待变身动画结束后才能播放。

### 彩虹狂热

1. 三次点击彩虹龙头分别产生三圈脉冲，文字与「Gon Gon GonGonGonGon」同步。
2. 推动腰带拉杆，彩虹炼金阵展开。
3. 蒸汽列车模型在炼金阵中放大并与脚部一体化。
4. 刺猬人沿彩虹铁轨冲向目标，以火车头骑士踢贯穿主目标。
5. 其他目标只承受扩散的彩虹列车余波。
6. 彩虹炼金能量回流，播放恢复和净化效果。

## 10. 悲愿不倒与悲愿反扑

- 致死瞬间角色卡先灰暗并出现裂纹。
- 胸口重新燃起黑绿火焰，彩虹炼金线把装甲强行缝回。
- 生命停在锁定值，清除异常与获得防护的状态同步显现。
- 紧接着的《悲愿反扑》与复活动画组成一条连续镜头，不能隔着无关日志突然发动连斩。

## 11. 实现约束

- 建立独立的刺猬人特效系统，不复用小汀或牢鳄的画布主题。
- 所有特效定位绑定角色与目标节点，禁止默认落在战场中心。
- 伤害数字、目标受击与战斗日志必须在真正的命中帧同步出现。
- 每次行动只有第一条权威技能事件启动动画，后续伤害说明日志不能重复播放动作。
- 随机技能变体由战斗事件提供结构化视觉标识，界面不依赖文本正则猜测。
- 多目标连斩必须拥有逐目标路径和逐目标命中时刻。
- 变身、立即反击与必杀进入同一动画队列，严格串行播放。
- 为每个技能建立独立开发预览入口，分别验证桌面端和手机横屏。
- 提供低动态版本：关闭大幅位移、镜头震动和长时间闪光，同时保留技能辨识度。

## 12. 图片资源清单

最低需要：

1. 奇迹武刃透明底全身立绘。
2. 奇迹怪兽武刃透明底全身立绘。
3. 黑色武神之刃独立透明图。
4. 怪兽拳套独立透明图。
5. 武神王座透明图。
6. 彩虹龙头或腰带近景透明图。
7. 蒸汽列车模型透明图。
8. 一、二、三阶段方形头像；其中二、三阶段为必需。

资源建议：

- 原图使用透明 PNG，接入项目时统一转换为 WebP。
- 全身立绘高度至少 1600px。
- 完整保留头、脚、武器和披风。
- 不携带背景、文字、预制光效和边缘裁切。
- 独立武器、拳套、王座和列车素材应保留透明边缘，方便在不同目标方向下旋转和缩放。
