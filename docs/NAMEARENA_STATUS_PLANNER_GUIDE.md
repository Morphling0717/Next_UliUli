# 名字大乱斗：状态系统重做策划手册

> 文档用途：供游戏策划设计、审核新角色与新技能使用。本文只描述玩家能感受到的玩法规则，不涉及程序实现。
>
> 当前状态：重做方案定稿，尚未实装。文中的具体数值是第一版测试基准，之后可以依据实战调整，但状态的核心定位与相互区别应保持稳定。

灼烧与流血的新规则是玩法重做，不是只换一个名字的无损迁移。现有角色转入新规则时，必须独立复查技能施加量、触发频率与胜率。

本文逐项列出本次重做后可供不同角色复用的全部通用状态，并补充现有的重要控制与防御规则。角色专属形态、装备、关系、标记和剧情状态只说明统一边界，详细效果继续以各角色自己的设计文档为准。

## 一、这次重做后，游戏会变成什么样

### 1. 每种通用状态都有唯一玩法

过去有些状态只是换了角色名和描述，实际效果完全相同。重做后，所有可复用效果都会使用统一的玩法关键词。

例如，丝瓜uli 的【闪光曲球】仍然显示这个名字、图标和技能文案，但详情会明确写出它属于【偏离 55】，也就是让命中率降低 55 个百分点。以后其他角色也可以制造【偏离】，但不需要复制一套相同规则。

角色特色不会因此被抹平。角色名、技能名、图标、动画、台词和日志仍然由角色自己决定；统一的只是实际效果与结算规则。

### 2. 所有状态都能看懂

玩家可以查看任意状态的完整说明，包括：

- 它具体改变什么数值。
- 当前强度、剩余触发次数或剩余时间。
- 什么时候触发、什么时候消失。
- 由谁、通过哪个技能施加。
- 能否被驱散，是否必须使用强驱散。

桌面端可悬停或聚焦查看，手机端可点击查看，角色详情中也会保留完整状态列表。状态栏不再出现英文代号或只有名字没有效果的状态。

### 3. 玩家与召唤物拥有完整士气

所有玩家角色与普通召唤物都以 100 点士气入场。士气降低会逐渐影响暴击与伤害，降到 0 时会精神崩溃。非玩家角色没有士气，但【沉沦】对它们仍有替代效果，不会完全失效。

### 4. 驱散分为两个等级

技能效果分为【可驱散】【仅强驱散】【不可驱散】三类；清除手段分为【驱散】与【强驱散】两级。这样策划写技能时能准确控制净化强度，不再用“清除异常”模糊带过。

### 5. 状态组合会产生明确流派

新角色可以围绕以下路线形成完整循环：

- 积累【灼烧】等待大回合结算，或用【爆燃】提前释放火势。
- 施加【流血】惩罚敌人的攻击行为，再用【催血】主动维持伤害循环。
- 施加【破裂】，再用攻击连续触发伤口伤害。
- 积累【震颤】，再用震颤爆发制造【踉跄】窗口。
- 施加【沉沦】，压低士气并迫使目标精神崩溃。
- 积累【呼吸】，稳定制造暴击。
- 积累【充能】，再消费充能强化技能。
- 组合命中、闪避、攻防、治疗与屏障关键词，形成支援或压制角色。

一个角色最好拥有一条主要循环和少量辅助状态，而不是把所有关键词都塞进同一技能组。

## 二、策划如何阅读和书写状态

### 1. 四种常见数值写法

| 写法 | 含义 | 示例 |
| --- | --- | --- |
| 强度 × 次数 | 每次触发有多强，以及还能触发几次 | 【破裂 8×3】表示每次按强度 8 结算，还能触发 3 次 |
| 数值 + 持续时间 | 效果幅度，以及还能持续多久 | 【迅捷 20% · 2次自身行动机会】 |
| 数值 + 可用次数 | 接下来几次符合条件的行动会使用它 | 【洞察 30 · 2次攻击】 |
| 当前值 / 上限 | 角色主动积攒和消费的资源 | 【充能 14/20】 |

不要把“持续三次行动”和“最多触发三次”混为一谈。一个状态可以持续三次自身行动，但在此期间最多触发一次；也可以没有固定持续时间，只在触发次数归零后消失。

### 2. 时间单位

| 时间单位 | 什么时候向前计算 |
| --- | --- |
| 自身行动机会 | 状态拥有者轮到一次行动后。即使被眩晕或击飞而无法出手，这次机会仍然经过 |
| 完成一次攻击 | 只有真正执行了攻击才计算；治疗、召唤或被控制跳过行动都不算 |
| 全局行动 | 场上任意单位完成一次实际行动后 |
| 大回合 | 所有本轮应行动的单位都完成一次行动机会后 |
| 触发消耗 | 只有满足状态指定条件时才消耗 |
| 永久 | 不自然消失，只能被替换、点名移除或随角色生命周期结束 |

场外 OB 的角色没有自身行动机会，因此自身持续伤害、持续治疗、士气恢复和自身计时都会暂停；专门负责让角色回场的计时仍会继续。

### 3. 叠加与来源

- 【灼烧】【流血】【破裂】【震颤】【沉沦】【呼吸】再次施加时，强度和次数分别相加，各自达到上限后停止增长。
- 溢出的强度不会自动变成次数，溢出的次数也不会变成强度。想做这种转换，必须在技能文本中明确写出。
- 同一种状态来自多名角色时，每一份来源都会保留。状态卡默认显示最新施加者，后续状态伤害、击杀和统计也归最新施加者。
- 最新一份效果到期后，显示与归属会回到仍在生效的次新来源。
- 同一技能同时给予多个普通效果时，界面只显示一张有角色主题的状态卡，展开后再看完整效果，避免状态栏被图标塞满。

### 4. 上限原则

游戏没有“所有增益最多只能叠到某个百分比”的隐藏通用上限。只有可能因高频叠加明显失控的状态才设置公开上限。

当前第一版硬上限为：

| 状态 | 上限 |
| --- | --- |
| 士气 | 0 至 100 |
| 灼烧 | 强度 20，次数 6 |
| 流血 | 强度 20，次数 6 |
| 破裂 | 强度 20，次数 6 |
| 震颤 | 强度 20，次数 6 |
| 沉沦 | 强度 20，次数 6 |
| 呼吸 | 强度 10，次数 6 |
| 充能 | 20 |

概率不会低于 0% 或高于 100%，伤害和治疗不会计算成负数，行动间隔也不能降为零。这些属于基本有效性保护，不是角色平衡上限。

### 5. 正反状态同时存在时

重做后新设计的技能默认遵守以下规则：

- 同方向的百分比先相加。例如两份【威势 15】合计为【威势 30】。
- 互为正反的效果不会简单互相减层，而是分别结算。例如【威势 30】与【衰弱 20】同时存在时，先把输出提高 30%，再把提高后的结果降低 20%。
- 易损/防护、强攻/怯攻、盈魔/枯魔、明识/迷惘、疾行/迟行、灵巧/滞身、迅捷/束缚、坚固/破防、甲胄/裂甲、灵障/蚀障、生机/枯竭也遵守相同原则。
- 命中率、暴击率与暴击额外伤害使用“百分点”，正反效果直接在对应概率或倍率上加减，最后限制在合法范围内。
- 如果某个技能要改成“只取最高”“覆盖旧值”“两种状态互斥”或其他特殊方式，必须在玩家可查看的效果中明确写出。

这套默认只用于重做后新设计的技能。现有角色会保留当前真实的累加、乘算、取最高、最低值和取整方式，不会因为换成统一关键词就改变伤害或胜率。

## 三、核心状态体系

### 1. 灼烧

**定位：** 按大回合稳定结算的蓄热伤害，可以为持续压制保留，也可以被技能提前引爆。

- 使用“强度 × 次数”，上限为 `20×6`。
- 每个大回合结束时，仍在战场上的持有者受到 `灼烧强度×6` 点固定伤害，并消耗 1 次。
- 再次施加灼烧时，强度和次数分别相加，各自达到上限后停止增长。
- 灼烧忽略防御和魔抗，但可以被屏障吸收；屏障只挡伤害，不清除灼烧。
- 场外 OB 期间不结算灼烧，也不消耗次数。
- 次数归零时消失，默认属于【可驱散】负面状态。

#### 爆燃

【爆燃】不是一个要挂在状态栏的新状态，而是技能对灼烧执行的操作。

- 立即结算 1 次灼烧伤害，并消耗 1 次灼烧。
- 想要连续爆燃，技能必须明确写出次数；每次都要消耗灼烧次数。
- 只是再次施加灼烧时不会自动爆燃。

灼烧流派因此有两种写法：叠高强度与次数做长线伤害，或者用爆燃牺牲剩余次数换取立即爆发。

### 2. 流血

**定位：** 惩罚主动攻击的伤口状态，同时作为未来血魔体系的基础燃料。

- 使用“强度 × 次数”，上限为 `20×6`。
- 当持有者将要执行一次有效的主动攻击时，在攻击造成伤害前，先受到 `流血强度×6` 点固定伤害，并消耗 1 次。
- 攻击最终未命中也会流血，因为伤口在出手前已经裂开。
- 若因眩晕、击飞、尴尬等原因没有真正发动攻击，则不触发也不消耗流血。
- 治疗、增益、召唤、纯控制、反击、反射和伤害转移不触发流血。
- 一次攻击行动默认只触发 1 次。真实多段技能想多次触发，必须在技能说明中写明。
- 流血忽略防御与魔抗，默认绕过屏障。
- 流血若在攻击前使角色真正死亡，该次攻击取消。
- 次数归零时消失，默认属于【可驱散】负面状态。

#### 流血相关关键词

| 关键词 | 作用 | 是否占用状态栏 |
| --- | --- | --- |
| 催血 | 立即触发目标 1 次流血并消耗 1 次；技能可明确写出多次催血 | 否 |
| 止血 | 移除全部流血，或按技能文本削减指定强度/次数 | 否 |
| 枯竭 | 降低受到的治疗、再生与吸血，是独立负面状态 | 是 |
| 血宴 | 记录流血实际造成的生命伤害，是血魔专属战场资源 | 只显示在血魔体系界面 |
| 硬血 | 血魔消耗血宴锻造的个人资源，用于成长与强化技能 | 只属于血魔 |

【血宴】与【硬血】的详细循环见 [单核血魔角色开发方向](./NAMEARENA_BLOODFIEND_DIRECTION.md)。

必须保持下列边界：

- 流血不再自带治疗削弱。需要禁疗或减疗时，另外施加【枯竭】。
- 【催血】和【止血】是技能动作，不是给状态栏多塞两个图标。
- 通用流血角色可以施加或催动流血，但不会凭空获得血宴与硬血。
- 【血宴】只记录流血实际扣掉的生命，不记录过量伤害，也不因转移或均摊重复计算。

### 3. 中毒

**定位：** 逐步叠高的体内持续伤害。

- 中毒最多 3 层。
- 目标每次自身行动开始时，1/2/3 层分别损失最大生命的 4%/5%/6%。
- 再次施加中毒会增加 1 层并刷新持续时间。
- 中毒属于体内伤害，默认绕过屏障。
- 默认属于【可驱散】负面状态。

### 4. 破裂

**定位：** 集火、多段攻击和对抗高防御目标。

- 使用“强度 × 次数”，上限为 20×6。
- 带有破裂的单位受到一次真正造成生命伤害的直接攻击时，额外结算一次破裂伤害，并消耗 1 次。
- 强度低于 20 时，每点强度造成 6 点固定伤害。
- 强度达到 20 时，改为造成目标最大生命 4% 的伤害，且最低为 120 点。
- 破裂伤害忽略防御与魔抗，默认绕过屏障。
- 未命中、无敌、法术抵挡或屏障完全吸收本次攻击时，不触发也不消耗破裂。
- 持续伤害、反伤、伤害均摊、自残、落地伤害和环境伤害不能触发破裂。
- 破裂伤害不会继续触发破裂、沉沦或其他受击状态。
- 默认属于【可驱散】负面状态。

### 5. 震颤与踉跄

**定位：** 先积累，再由特定技能制造集火窗口。

【震颤】规则：

- 使用“强度 × 次数”，上限为 20×6。
- 震颤本身不造成伤害，也不会自动控制目标。
- 只有明确写有“震颤爆发”的技能才能引爆。
- 每次爆发把等于震颤强度的数值加入目标的失衡值，并消耗 1 次震颤。
- 目标每经过一次自身行动机会，震颤次数还会自然减少 1。
- 失衡值不会自然下降。达到 40 时，目标进入【踉跄】，失衡值归零。

【踉跄】规则：

- 持续到目标下一次自身行动机会结束。
- 目标仍然可以行动，但闪避归零，不能反击、等待反击或受击截停。
- 受到的非持续直接伤害提高 25%。
- 踉跄期间不能再次进入踉跄，但新的失衡值可以保留到踉跄结束后。
- 默认属于【可驱散】负面状态。

震颤不是换皮眩晕。它的核心价值是创造一个可预告、可协作利用的输出窗口。

### 6. 沉沦、士气与精神崩溃

**定位：** 通过精神压制削弱目标，而不是制造另一种生命持续伤害。

【沉沦】规则：

- 使用“强度 × 次数”，上限为 20×6。
- 带有沉沦的单位受到一次真正造成生命伤害的直接攻击时，士气降低等于沉沦强度的数值，并消耗 1 次沉沦。
- 未命中、无敌、法术抵挡、屏障完全吸收或伤害被其他单位接走时，原目标不降低士气。
- 默认属于【可驱散】负面状态。

【士气】规则：

- 玩家角色与普通召唤物以 100 点士气入场，士气范围为 0 至 100。
- 51 至 100：没有额外惩罚。
- 26 至 50：普通暴击率降低 10 个百分点。
- 1 至 25：普通暴击率降低 10 个百分点，直接攻击造成的伤害再降低 15%。状态伤害、反伤、伤害转移、伤害均摊、自残与环境伤害不受影响。
- 士气降到 0 时触发一次【精神崩溃】，随后士气恢复到 50，避免连续崩溃。
- 每次自身行动机会结束时，如果从上一次自身行动机会结束至今没有损失过士气，就恢复 10 点士气。
- 被控制而无法行动仍会检查自然恢复；场外 OB 时不会恢复。
- 普通转阶段默认保留当前士气。真正死亡会清除士气，默认复活后以 100 点士气重新入场。

【精神崩溃】规则：

- 下一次真正完成的行动只能使用普通攻击，而且不能暴击。
- 如果这次行动机会被眩晕、击飞等效果阻止，精神崩溃不会消耗，直到角色真正完成一次普通攻击。
- 默认属于【仅强驱散】负面状态。

【沉沦对非玩家角色】规则：

- 非玩家角色没有士气，也不会精神崩溃。
- 沉沦被攻击触发时，改为造成等于沉沦强度的固定伤害并消耗 1 次。
- 这份替代伤害忽略防御与魔抗，但可以被屏障吸收，也不会继续触发其他受击状态。

### 7. 呼吸

**定位：** 可积累、可消耗的暴击路线。

- 使用“强度 × 次数”，上限为 10×6。
- 每点呼吸强度增加 5 个百分点暴击率，满强度为增加 50 个百分点。
- 只有真正打出暴击时才消耗 1 次呼吸；没有暴击就不消耗。
- 必定暴击成功时也会消耗 1 次呼吸。
- 呼吸只提高暴击率，不提高暴击伤害。
- 默认属于【可驱散】正面状态。

### 8. 充能

**定位：** 先积攒，再消费的技能资源。

- 充能上限为 20，本身不提高任何属性。
- 每经过一次自身行动机会，自然减少 1 点。
- 技能可以消费充能来增加伤害、获得屏障、追加攻击、强化异常或改变技能形态。
- 充能不足时，技能默认使用未强化版本；除非技能明确写出“充能不足则无法使用”。
- 充能是不可驱散的中性资源。只有明确写出“清除充能”“夺取充能”或“消耗充能”的能力才能改变它。

## 四、行动与行为状态

这些状态虽然都会影响行动，但效果不同，不能互相换皮。

| 状态 | 精确效果 | 默认驱散等级 |
| --- | --- | --- |
| 眩晕 | 无法行动 | 仅强驱散 |
| 冰冻 | 无法行动，同时物理防御归零 | 仅强驱散 |
| 混乱 | 只能普通攻击，并随机攻击场上另一名合法单位，可能攻击队友，不会攻击自己 | 仅强驱散 |
| 尴尬 | 行动时有 50% 概率无法出手；判定成功时照常行动 | 仅强驱散 |
| 魅惑 | 选目标时尽量避开魅惑来源；如果没有其他合法目标而必须攻击来源，伤害降低 60% 且不能暴击 | 仅强驱散 |
| 沉默 | 可以行动，但只能普通攻击 | 可驱散 |
| 击飞 | 下一次自身行动机会无法行动，随后落地并损失最大生命的 3% | 仅强驱散 |
| 火力压制 | 无法行动，同时闪避归零 | 仅强驱散 |
| 水牢 | 无法行动、不能闪避、不能转移伤害；自身行动开始损失最大生命的 8% | 仅强驱散 |
| 麻痹 | 接下来若干次攻击固定使用伤害随机区间最低值，并且不能暴击 | 可驱散 |

额外规则：

- 麻痹只在真正执行攻击时消耗。治疗、增益、召唤和纯控制不消耗。
- 没有随机伤害区间的固定伤害攻击仍会消耗麻痹并被禁止暴击，但伤害数值不会额外降低。
- 强驱散【击飞】会让目标立刻落地并结算落地伤害，不会凭空悬在空中或吞掉伤害。
- 水牢的窒息伤害可以被屏障吸收，但屏障不会解除无法行动、无法闪避与无法转移。
- 混乱与尴尬必须保持独立。混乱改变攻击对象和行为，尴尬只进行一次能否出手的概率判定。

## 五、输出与属性状态

### 1. 最终输出

| 状态 | 效果 |
| --- | --- |
| 威势 X | 直接攻击的最终伤害提高 X% |
| 衰弱 X | 直接攻击的最终伤害降低 X% |

威势与衰弱可以限定为物理或魔法。它们默认不改变持续伤害、反伤、伤害转移、伤害均摊、自残、处决与环境伤害。

### 2. 基础战斗属性

| 状态 | 效果 |
| --- | --- |
| 强攻 X | 战斗中读取的攻击力提高 X% |
| 怯攻 X | 战斗中读取的攻击力降低 X% |
| 盈魔 X | 战斗中读取的魔力提高 X% |
| 枯魔 X | 战斗中读取的魔力降低 X% |
| 明识 X | 战斗中读取的智力提高 X% |
| 迷惘 X | 战斗中读取的智力降低 X% |
| 疾行 X | 战斗中读取的速度提高 X% |
| 迟行 X | 战斗中读取的速度降低 X% |
| 灵巧 X | 战斗中读取的敏捷提高 X% |
| 滞身 X | 战斗中读取的敏捷降低 X% |

基础属性变化不只影响普通伤害。只要某个技能的伤害、治疗、屏障或召唤物强度会读取该属性，它就会受到相应状态影响。状态结束后恢复原本属性，不会永久改写角色面板。

### 3. 迅捷与束缚

| 状态 | 效果 |
| --- | --- |
| 迅捷 X | 实际获得行动机会的速度提高 X% |
| 束缚 X | 实际获得行动机会的速度降低 X% |

迅捷与束缚只改变出手频率，不改变面板速度、闪避、技能伤害或冷却。两者同时存在时分别计算，不简单互相减层。

### 4. 最容易混淆的区别

| 容易混淆的状态 | 正确区别 |
| --- | --- |
| 威势 / 强攻 | 威势直接改最后的攻击伤害；强攻改攻击力，可能连带影响读取攻击力的治疗、屏障或召唤公式 |
| 衰弱 / 怯攻 | 衰弱削减最后输出；怯攻降低攻击力读取值 |
| 迅捷 / 疾行 | 迅捷只让角色更频繁行动；疾行提高速度属性，也可能强化依赖速度的技能 |
| 束缚 / 迟行 | 束缚只减少行动频率；迟行降低速度属性 |
| 灵巧 / 残影 | 灵巧提高敏捷属性，可能同时影响命中和闪避；残影只提高目标侧闪避能力 |
| 易损 / 破防 | 易损提高最后受到的直接伤害；破防降低防御与魔抗，只影响会读取双抗的伤害 |
| 防护 / 坚固 | 防护降低最后受到的直接伤害；坚固提高防御与魔抗，不会降低无视双抗的伤害 |
| 洞察 / 残影 | 洞察提高攻击者命中；残影提高目标闪避，两者作用在命中判定的不同一侧 |

未来新技能如果只是想“伤害提高 20%”，优先使用【威势 20】；如果想让整套依赖攻击力的能力一起成长，才使用【强攻 20】。

## 六、防御、承伤与屏障

### 1. 最终承伤

| 状态 | 效果 |
| --- | --- |
| 易损 X | 受到的非持续直接伤害提高 X% |
| 防护 X | 受到的非持续直接伤害降低 X% |

- 易损与防护默认不影响持续伤害、反伤、自残、生命支付、处决与环境伤害。
- 防护不是无敌。只要最终仍损失生命，合法的受击效果仍可触发。
- 新技能的普通易损和防护建议不超过 40%，这是设计建议而非隐藏硬上限。

### 2. 防御与魔抗

| 状态 | 效果 |
| --- | --- |
| 坚固 X | 防御和魔抗同时提高 X% |
| 破防 X | 防御和魔抗同时降低 X% |
| 甲胄 X | 只提高物理防御 X% |
| 裂甲 X | 只降低物理防御 X% |
| 灵障 X | 只提高魔抗 X% |
| 蚀障 X | 只降低魔抗 X% |

这些状态不影响真实伤害、固定伤害和明确无视双抗的技能。物理防御归零等绝对规则优先于普通百分比修正。

### 3. 屏障

- 【屏障 X】拥有 X 点独立护盾值。合法伤害先扣屏障，再扣生命。
- 屏障吸收量会显示在蓝色护盾条和战斗日志中。
- 多份普通屏障同时存在时，优先消耗最早到期的一份；到期相同则优先消耗最早获得的一份。
- 普通通用屏障建议合计不超过角色最大生命的 40%。专属护盾可以例外，但必须明写。
- 同一来源再次提供屏障时，技能必须写清是刷新持续时间、补充护盾还是覆盖旧值。

默认屏障交互：

| 伤害来源 | 是否被屏障吸收 |
| --- | --- |
| 普通攻击与一般技能伤害 | 是 |
| 灼烧 | 是 |
| 水牢窒息 | 是 |
| 无士气非玩家角色受到的沉沦替代伤害 | 是 |
| 流血 | 否 |
| 中毒 | 否 |
| 破裂 | 否 |
| 矿石病 | 否 |
| 自残与主动生命支付 | 否 |
| 击飞落地与环境伤害 | 否 |
| 明确写出无视护盾的处决 | 否 |

### 4. 独立防御状态

以下效果必须保持独立，不能用防护或屏障换皮：

| 状态 | 效果 |
| --- | --- |
| 无敌 | 免疫伤害，但默认不等于控制免疫；附加状态是否成立仍按该状态自己的命中与免疫规则处理 |
| 控制免疫 | 阻止控制状态被施加，不会自动清除已经存在的控制 |
| 法术抵挡 | 完整挡下下一次合法技能伤害或控制，使用后消失；名称与日志必须显示真正来源 |
| 虚无 | 免疫物理伤害，受到魔法伤害翻倍，同时无法进行物理攻击 |

无敌、防护、屏障、控制免疫和法术抵挡是五种不同的防御层，策划不能只写“获得保护”。

## 七、命中、闪避与暴击

### 1. 命中与闪避

| 状态 | 效果 |
| --- | --- |
| 洞察 X | 接下来若干次攻击的最终命中率提高 X 个百分点 |
| 偏离 X | 接下来若干次攻击的最终命中率降低 X 个百分点 |
| 残影 X | 目标侧的闪避能力提高 X% |
| 失位 X | 目标侧的闪避能力降低 X%；【失位 100】表示闪避归零 |
| 仇恨值 X | 该单位在敌方随机选目标时，基础被选中权重提高 X% |

- 洞察与偏离在真正进行一次命中判定后才消耗。
- 必中、必定落空和特殊截停优先于普通命中修正。
- 残影与失位只改变目标侧闪避，不改变攻击者命中。
- 仇恨值只提高概率，不是强制嘲讽。角色专属标记、剧情目标与硬嘲讽仍可以覆盖它。
- 无法被选中或处于场外 OB 的单位不会因为仇恨值重新成为目标。

### 2. 暴击

| 状态 | 效果 |
| --- | --- |
| 呼吸 | 提高自身暴击率，暴击后消耗次数 |
| 破绽 X | 攻击该目标时，暴击率提高 X 个百分点；【破绽 100】表示合法攻击必暴击 |
| 锐意 X | 接下来若干次暴击的额外伤害提高 X 个百分点 |
| 钝化 X | 接下来若干次受到的暴击，其额外伤害降低 X 个百分点 |
| 锁头 | 下一次攻击必中且必定暴击 |

- 呼吸提高攻击者自身暴击率；破绽让所有攻击该目标的人更容易暴击。
- 锐意和钝化只改暴击倍率，不改暴击率。
- 钝化最多把暴击削弱为普通命中的伤害，不能让暴击伤害反而更低。
- 锁头是独立的高优先级规则，不等于【洞察 100】加【呼吸 20】。

## 八、治疗、吸血与持续恢复

| 状态 | 效果 |
| --- | --- |
| 生机 X | 受到的治疗、再生与合法吸血提高 X% |
| 枯竭 X | 受到的治疗、再生与合法吸血降低 X% |
| 枯竭 100 | 完全禁疗 |
| 汲取 X | 接下来若干次直接攻击造成生命伤害后，按实际生命损失的 X% 治疗攻击者 |
| 再生 | 在技能指定的结算时点持续恢复生命；技能必须明写每次恢复量与持续时间 |

通用规则：

- 最大生命提高、转阶段设置生命、复活设置生命和锁血都不属于治疗，不受生机与枯竭影响。
- 治疗最低为 0。枯竭超过 100 也不会把治疗反转成伤害；治疗反转必须作为独立机制设计。
- 汲取只以目标实际损失的生命为基数，不计算过量伤害和被屏障吸收的伤害。
- 未命中、被无敌或法术抵挡挡下、以及屏障完全吸收时，不消耗汲取次数。
- 持续伤害、反伤、状态伤害、环境伤害和普通召唤物伤害默认不触发汲取。
- 想让召唤物伤害治疗主人，应明确写成召唤物专属吸血关系，例如牢鳄的【吸血牌】。
- 完全禁疗时，战斗日志仍会写出“汲取已经触发，但治疗被阻止”，不能无声消失。

普通汲取建议不超过 50%。超过这一数值时，应作为角色专属高价值效果处理。

## 九、驱散体系

### 1. 三种状态等级

| 状态等级 | 驱散 | 强驱散 |
| --- | --- | --- |
| 可驱散 | 可以移除 | 可以移除 |
| 仅强驱散 | 无法移除 | 可以移除 |
| 不可驱散 | 无法移除 | 无法移除 |

### 2. 默认方向

- 对友方使用驱散，默认只移除负面效果。
- 对敌方使用驱散，默认只移除正面效果。
- 想同时移除正面与负面，技能必须明确写“驱散全部可驱散效果”。
- 充能、仇恨值、角色资源和剧情标记等中性效果默认不受驱散影响，只能被点名清除、夺取或消费。
- 强驱散不是删除所有状态，仍然不能移除不可驱散效果。

### 3. 默认分类

| 等级 | 常见状态 |
| --- | --- |
| 可驱散 | 灼烧、中毒、流血、破裂、震颤、踉跄、沉沦、易损、防护、麻痹、迅捷、束缚、威势/衰弱、普通属性强化/削弱、命中/闪避修正、治疗修正、普通屏障、呼吸、锐意/钝化、汲取、破绽、沉默 |
| 仅强驱散 | 眩晕、冰冻、混乱、尴尬、魅惑、击飞、火力压制、水牢、精神崩溃等强行改变行动或行为的控制 |
| 不可驱散 | 角色形态、致死保护、复活资格、场外 OB、召唤与主人关系、装备身份、仇恨值与硬嘲讽、角色专属资源、冷却标记、非玩家事件阶段、专属剧情标记 |

同一种通用效果可以因来源不同而改变驱散等级。例如普通技能给予的屏障可以驱散，剧情形态附带的护盾可以不可驱散，但技能文本必须明确说明。

### 4. 现有角色的强驱散定位

以下是重做后现有角色预定拥有的高级净化能力，供新角色设计时参考强度基准：

| 角色与能力 | 重做后的定位 |
| --- | --- |
| 兔卷卷【CE清除】 | 友方全体强驱散，只清除负面效果 |
| 兔卷卷【归零】 | 敌方单体强驱散，只移除正面效果 |
| 丝瓜uli【宇宙分裂】 | 友方全体强驱散，之后再给予无敌 |
| 玄凝【1vX残局】 | 自身强驱散，清理硬控后进入残局反打 |
| M1【王牌乘员抢修】【顶级魔法跳弹】 | 自身强驱散；灭火、洗消、止血和模块修复仍按异常种类分别描述 |
| 鸮进入【哀兵】 | 转入战争形态时自身强驱散，矿石病等不可驱散效果保留 |
| 刺猬人高级炼金与三阶段必杀 | 高级形态重构时自身强驱散；一阶段【特摄魂】仍是普通驱散 |
| 刺猬人【悲愿共鸣·武神王座】 | 只强驱散妨碍入座的硬控与沉默，不清除其他负面效果 |
| 牢鳄【小保底】【氪金改命】 | 对应命运改写真正触发时，自身强驱散 |
| 牢鳄欧皇形态的钞能力解控 | 只解除行动控制与沉默，不顺带清除持续伤害和属性削弱 |
| 小汀【爆鳄余烬】 | 亲手击倒牢鳄后，自身强驱散 |
| 屑【再生·血肉重铸】 | 自身强驱散，但不清除插件、形态与不可驱散身份 |

普通支援池的“清除异常”、萌月沫沫为舰长净化、玄凝【喝瓶取消】、刺猬人一阶段【特摄魂】仍属于普通驱散。战雷的灭火、洗消、止血和模块修理属于点名处理，不应统称为“强驱散一切”。

### 5. 规格外例外

水人有意作为规格外最强角色：

- 水人的否决可以清除充能、仇恨值等普通驱散不会触碰的中性资源。
- 否决可以按已知特例移除【不甘倒下】与【悲愿不倒】。
- 水人的处决与否决不会斩杀一阶段转入二阶段时的锁血。
- “规格外”不代表一句话删除所有角色形态和剧情事件，具体例外仍需在技能中点名。

其他角色不能复制水人的绝对清除权限。

## 十、攻击、拦截、分伤与状态触发

策划写技能时必须遵守以下共同规则，否则同一个技能在傀儡、均摊或转阶段场景中会出现前后矛盾。

### 1. 先确定真正目标，再判定命中

- 先选出技能原本想攻击的目标。
- 如果傀儡小汀等机制在攻击前完成拦截，先把真正目标换成拦截者。
- 命中、闪避、防御和受击状态都以换位后的真正目标为准，同时保留原始目标用于日志和角色机制判断。
- 某种拦截若写明“必定挡下”，可以直接保证拦截成功；否则不能偷偷沿用原目标的闪避率。

### 2. 状态只检查真正承伤者

- 攻击被傀儡挡下时，只检查傀儡身上的破裂、沉沦、屏障和受击效果。
- 伤害被源石结晶、帝王之征或其他单位接走时，只检查最终承受该份伤害的单位。
- 伤害均摊与伤害转移不会让同一次攻击重复消耗攻击者的“一次攻击”状态。
- 状态额外伤害不会再次触发另一轮状态额外伤害，防止无限连锁。

### 3. 多段攻击必须写清真实命中次数

策划应在技能文案中明确：

- 是一次伤害，只在表现上连续斩击；还是
- 多次独立伤害，每一段都能分别命中、触发状态和处理护盾；还是
- 基础伤害只结算一次，但某个状态允许按若干次命中触发。

不能只写“攻击九次”却不说明破裂、沉沦、呼吸、汲取和屏障究竟结算几次。

### 4. 转阶段与死亡

- 同一击已经触发锁血或转阶段后，后续追加的破裂、沉沦等受击状态不会继续伤害新阶段，也不会白白消耗次数。
- 真正死亡会清除普通正面与负面状态、士气和失衡值。
- 转阶段清除哪些状态，继续遵守每个角色自己的设计；没有特别说明时保留当前士气。
- 默认复活以 100 点士气重新入场。需要“带着低士气复活”的技能必须明写。
- 状态施加者先死亡，不会抹掉已经施加的状态来源；后续状态击杀仍会正确归属。

## 十一、哪些机制必须保持角色专属

以下机制不应为了“统一状态”而改成普通关键词：

- 一阶段、二阶段、三阶段与职业形态。
- 锁血、不甘倒下、悲愿不倒、复活资格和其他致死保护。
- 反击、等待反击、受击截停、魅惑反击与专属反击姿态。
- 场外 OB、无法选中、剧情退场与非玩家角色阶段。
- 召唤物、主人、舰长、认主、傀儡小汀、帝王之征和高级召唤物关系。
- 脊髓剑、村好剑、醒剑、插件和女人风格等装备或身份。
- 柚子镜界标记、鸮过江标记、战雷侦察、矿石病等专属标记。
- 水之幻影、专属护盾、专属无敌与其他有特殊边界的防御。
- 天意、欧气、APM、众宾欢也等角色资源与冷却标记。

这些机制可以在其中使用通用状态。例如一个专属形态可以同时给予【强攻 20】和【灵障 15】，但形态本身仍然是不可驱散的独立身份。

反击类能力没有一套通用伤害模板。每个反击都必须分别写清触发条件、触发概率、伤害或状态效果、能否打断原攻击、每次姿态可触发几次，以及触发后是否结束姿态。

判断标准很简单：如果移除名字后，它仍然只是“攻击提高 20%”，就应使用通用关键词；如果它会改变技能池、目标关系、行动方式、死亡规则、阶段或召唤关系，就应保留专属机制。

## 十二、新角色设计方法

### 1. 先确定一条主要循环

建议从以下方向选择一条：

| 角色方向 | 推荐循环 |
| --- | --- |
| 灼烧输出 | 施加灼烧，选择保留次数持续施压，或用爆燃提前消耗 |
| 流血输出 | 同时维持流血强度与次数，等待攻击触发或主动催血 |
| 追击型输出 | 施加破裂，再用多段攻击消费次数 |
| 团队破防手 | 施加震颤，自己或队友用震颤爆发制造踉跄 |
| 精神压制者 | 施加沉沦，围绕低士气和精神崩溃获得收益 |
| 暴击角色 | 积累呼吸，再用高价值攻击消费 |
| 资源循环角色 | 获取充能，选择立即消费或继续储存 |
| 坦克 | 防护、甲胄/灵障、屏障、仇恨值与少量反制 |
| 支援 | 生机、再生、属性增益、驱散或强驱散 |
| 扰乱者 | 偏离、失位、束缚、枯竭与软控制 |

一个角色可以有副路线，但主循环必须能从技能描述中一眼看出。不要让角色同时成为破裂、震颤、沉沦、呼吸和充能大师。

### 2. 再决定角色真正独特的部分

通用状态负责稳定规则，角色特色负责改变使用方式。例如：

- 普通破裂角色靠连续攻击触发；专属角色可以把满层破裂改造成一次处决窗口。
- 普通震颤角色只负责积累；专属角色可以在踉跄期间改变技能组。
- 普通充能角色消费固定数值；专属角色可以在低充能与高充能之间切换两套战斗风格。
- 普通支援给予屏障；专属支援可以让屏障破碎时发动一次角色主题技能。

独特机制应该改变决策，而不只是把相同数值换一个更华丽的名字。

### 3. 每个技能必须写清的内容

策划稿至少要回答：

1. 技能是普攻、一般技能、必杀、被动还是反击。
2. 目标是谁，单体还是多人，最多影响几人，能否选择召唤物或非玩家角色。
3. 造成物理、魔法、真实、固定、状态还是环境伤害。
4. 多段表现究竟结算几次伤害、几次状态触发。
5. 施加什么状态，强度、次数、持续时间分别是多少。
6. 状态在什么时候触发和消耗。
7. 状态是可驱散、仅强驱散还是不可驱散。
8. 伤害或状态是否被屏障吸收，是否无视防御、防护、无敌或法术抵挡。
9. 遇到拦截、分伤、锁血、转阶段、复活和目标死亡时如何处理。
10. 战斗日志需要怎样写出前因、目标、数值、结果和状态剩余量。

### 4. 推荐的状态文案格式

```text
【技能名】
类型：一般技能，单体魔法攻击
效果：对一名敌人造成明确数值的魔法伤害，并施加【沉沦 8×2】。
触发：目标之后受到真正造成生命伤害的直接攻击时，士气降低 8 点并消耗 1 次。
驱散：沉沦可驱散。
特殊边界：本技能只结算一次状态命中；若攻击被傀儡拦截，沉沦施加给傀儡。
```

这段格式不是要求所有游戏内文本都如此冗长，而是策划底稿必须先把规则写完整，之后再提炼为玩家看到的短文案。

## 十三、常见设计错误

### 1. 用不同名字重复同一个效果

错误：为新角色新建“神速”“加速领域”“飞驰”，三者全都是行动速度提高 20%。

正确：三者都使用【迅捷 20】，保留不同技能名、图标、动画和来源描述。

### 2. 把不同效果误写成同一个状态

错误：把眩晕、尴尬、混乱和魅惑全写成“无法行动”。

正确：眩晕必定无法行动；尴尬有 50% 失败；混乱强制随机普通攻击；魅惑改变选目标与对来源伤害。

### 3. 状态没有精确数值

错误：“大幅降低敌人的攻击和速度，持续一段时间。”

正确：“施加【怯攻 25】与【束缚 20】，持续 2 次目标自身行动机会。”

### 4. 没写触发与消耗

错误：“攻击九次后解锁必杀。”

正确：“每个大回合最多记录一次；只有技能命中标记目标才计数；累计九次后解锁必杀，使用后清零。”

### 5. 把防御效果混在一起

错误：“获得护盾并免疫控制和伤害。”

正确：分别写清屏障点数、防护百分比、无敌持续时间、控制免疫范围和法术抵挡次数。

### 6. 让状态伤害无限套娃

错误：破裂触发沉沦，沉沦替代伤害又触发破裂，最终形成无限连锁。

正确：状态追加伤害不会再触发其他受击状态。

## 十四、首版平衡参考

以下只是设计新技能时的普通参考区间，不是不可突破的硬上限。角色必杀、形态核心或有明确代价的能力可以超出，但需要单独审查。

| 状态 | 普通技能建议范围 |
| --- | --- |
| 灼烧 / 流血 | 单次通常施加 3 至 6 强度、1 至 2 次，需结合角色的施加频率审核 |
| 爆燃 / 催血 | 普通技能通常触发 1 次，连续触发应消费额外资源或属于必杀 |
| 易损 / 防护 | 单方向合计通常不超过 40% |
| 迅捷 / 束缚 | 单方向合计通常不超过 50% |
| 威势 / 衰弱 | 单方向合计通常不超过 50% |
| 坚固 | 通常不超过 60% |
| 破防 | 通常不超过 50% |
| 普通通用屏障 | 合计通常不超过最大生命 40% |
| 普通汲取 | 通常不超过 50% |
| 仇恨值 | 只提高被选中概率，不应冒充硬嘲讽 |

审核时优先看完整循环，而不是孤立看一个百分比。一个需要长时间积累、会被驱散、只能命中单体且使用后清空的高数值技能，与无条件常驻的同数值效果不能按同一标准评价。

## 十五、策划交稿检查表

新角色提交前，逐项确认：

- [ ] 主循环清晰，玩家能理解角色靠什么建立优势。
- [ ] 通用效果优先使用本手册中的关键词，没有重复制造换皮状态。
- [ ] 真正改变技能、目标、死亡、阶段或召唤关系的机制保留了专属身份。
- [ ] 每个状态都写了精确数值、持续时间或可用次数。
- [ ] 多段技能写清伤害次数与状态触发次数。
- [ ] 控制效果没有把眩晕、混乱、尴尬、魅惑、击飞等概念混用。
- [ ] 速度属性与行动频率、命中与闪避、暴击率与暴击伤害没有混用。
- [ ] 防护、屏障、无敌、控制免疫和法术抵挡分别写清。
- [ ] 写明普通驱散、强驱散与不可驱散等级。
- [ ] 写明与屏障、拦截、分伤、转阶段、锁血和复活的交互。
- [ ] 非玩家角色没有士气，普通召唤物拥有士气。
- [ ] 日志能够交代施加者、目标、实际数值、触发原因和结果。
- [ ] 没有让状态伤害递归触发状态伤害。
- [ ] 灼烧技能分清了“施加”与“爆燃”，流血技能分清了“施加”、“催血”与“止血”。
- [ ] 需要减疗的流血技能另外写明【枯竭】，没有把减疗当成流血自带效果。
- [ ] 超出首版建议范围的效果拥有明确代价、限制或角色定位理由。

完成这份检查后，新角色的技能设计就可以直接进入数值测试与战斗日志审查，不需要再依赖程序人员猜测策划原意。
