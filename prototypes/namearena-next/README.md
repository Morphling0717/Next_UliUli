# 名字大乱斗：竞技场 UI 独立原型

这是一个与现有名字大乱斗完全隔离的视觉原型，用来验证更接近正式游戏的舞台、HUD、角色演出和同步战报。

## 隔离说明

- 没有修改现有页面、组件、样式或游戏逻辑。
- 原型只读取 `public/Background.webp` 和 `public/Model.webp`，不会修改它们。
- 战斗数据由 `app.js` 内的固定演示脚本生成，不连接生产数据库，也不调用现有战斗引擎。
- 不采用时直接删除 `prototypes/namearena-next/` 即可，旧版不受任何影响。

## 本地预览

在仓库根目录运行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:4173/prototypes/namearena-next/
```

## 原型范围

- 全屏战场与角色空间布局
- 技能轨迹、粒子、伤害数字、受击震动
- 召唤卡、变身切入和普瑞赛斯事件干扰
- 与画面同步的行动分组战报
- 桌面、手机横屏和手机竖屏适配
- 暂停、重播、倍速、全屏与可选合成音效

若正式采用，下一步应把此视图接到现有战斗事件流，并将粒子层迁移到 PixiJS，以便处理更复杂的角色技能表现。
